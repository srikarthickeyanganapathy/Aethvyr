# FastStream Mobile 2.0

An accessible, customizable HLS / DASH / MP4 player and streaming optimizer for mobile and desktop browsers.

## Target browsers

- **Kiwi Browser / Chromium 111+** (Manifest V3 service worker)
- **Firefox for Android 128+** and Firefox desktop 128+ (Manifest V3 event page)

## How it works

```
player-overlay.js  (top frame, MAIN world, Shadow DOM UI + bundled Shaka Player)
      ⇅ private MessagePort (ArrayBuffers transferred, one-time nonce)
sniffer.js         (top frame, ISOLATED world: bridge + settings storage)
      ⇅ runtime port "faststream-player"
background/engine.js  → downloader.js (parallel prefetch, retry, backpressure, seek)
                      → abr-controller.js (throughput + buffer ABR)
                      → buffer-manager.js (IndexedDB ring buffer)
      ⇅ FETCH_PROXY {frameId}
sniffer.js + interceptor.js in the frame that owns the stream (page cookies / Referer)
```

## Project structure

```
FastStream Mobile/
├── manifest.json            # MV3 manifest (Chromium); Firefox variant generated by the build
├── common/shared.js         # Settings defaults/merge, base64 codec, URL classification
├── background/
│   ├── engine.js            # Detection, launch, sessions, telemetry, export, lifecycle
│   ├── downloader.js        # Segment loads, prefetch workers (2-8), retries, seek
│   ├── abr-controller.js    # Adaptive bitrate decisions
│   ├── buffer-manager.js    # IndexedDB ring buffer with eviction
│   └── hls-parser.js        # M3U8 parser, AES-128 decrypt helpers
├── content/
│   ├── interceptor.js       # MAIN world: stream detection + page-identity fetch proxy
│   ├── sniffer.js           # ISOLATED world: relay, DOM scan, proxy, media suspend, bridge
│   └── player-overlay.js    # Player UI (bundled with Shaka into player.bundle.js)
├── popup/                   # Stream picker, live stats, settings
├── rules/stream_rules.json  # Static DNR rule (exposes Content-Range etc. to the proxy)
├── icons/
└── scripts/
    ├── build.js             # Builds dist/chrome and dist/firefox (+ player bundle)
    └── package.js           # Zips the builds
```

## Getting started

```bash
npm install            # installs shaka-player (bundled locally, never loaded from a CDN)
npm run build:chrome   # -> dist/chrome
npm run build:firefox  # -> dist/firefox
npm run build          # both
npm run watch          # rebuild on change
npm run lint
npm run package        # zips in dist/
```

Always load the **built** folder (`dist/chrome` or `dist/firefox`): `content/player.bundle.js` only exists after a build.

### Loading the extension

**Kiwi Browser:** `chrome://extensions` → Developer mode → Load unpacked → `dist/chrome`.

**Firefox:** `about:debugging` → This Firefox → Load Temporary Add-on → any file in `dist/firefox`.
Firefox treats `<all_urls>` as opt-in for MV3: use the **Allow access to websites** button in the popup.

## Permissions

| Permission | Purpose |
|------------|---------|
| `<all_urls>` host access | Detect streams in every frame, proxy fetches, inject the player |
| `scripting` | Inject the player bundle into the top frame (CSP-proof) |
| `webRequest` | Detect manifests at network level (incl. workers), remember Referer |
| `declarativeNetRequest(+WithHostAccess)` | Static header rule + per-host Referer rule for fallback fetches |
| `storage`, `unlimitedStorage` | Settings, bookmarks, IndexedDB segment cache |
| `activeTab` | Popup access to the current tab |

## Known limitations

- DRM-protected streams (Widevine/PlayReady/FairPlay, SAMPLE-AES) cannot be played or exported.
- DASH export is not supported; HLS and direct files are.
- Separate HLS audio renditions are exported as a second file (not muxed into one MP4).
- Web Audio features (boost/EQ/delay) are unavailable for cross-origin direct files served without CORS.
- Sites whose CSP forbids `blob:` in `media-src` block MSE playback in the top frame.
