Start watching

  1. On a website Start its video, then choose Play in Aethvyr or pick a stream in the toolbar popup.
  2. On your device Drop a file onto the overlay or choose Open Local File in the popup on a supported website tab.
  3. While watching Open Studio with the sliders button. Use ? on a keyboard for the current shortcuts.

Playback and subtitles

Seek or find a chapter
Drag the seekbar or hover for time and a preview when available. Open Studio → Tools → Chapters to jump to a chapter or load a WebVTT chapter file.
Load subtitles
Open Subtitles & Audio with the captions button. Pick a track or load SRT, VTT, or ASS. Open the transcript to search and jump to a line.
Loop or watch in a small window
Use Studio → Tools for A–B loop, Mini player, and Picture in Picture where the browser supports it.

Downloads and clips

Save a supported stream
Open Studio → Tools → Download. Choose MP4 or Original when the source offers a choice. The toolbar download button uses that choice.
Save only a clip
Play through the range, then set In and Out under Clip from buffer. HLS and DASH clips follow cached segment boundaries.
Resume or re-export
Open Library → Offline / Cached. Choose Resume for a paused job or Export for a finished cache. Re-export an older short-timeline MP4 here if the source is still cached.

Get more from Studio

Quality
Select stream quality or let Auto adapt. Choose Eco, Balanced, Performance, or Custom for background prefetch.
Audio and Display
Balance volume with Smart loudness under Audio. Try Display → Graphics → Auto and use the comparison control to check the effect.
Preferences and diagnostics
Use Prefs → Player look to choose Minimal, Standard, or Pro controls. If playback fails, save a report under Tools → Save playback diagnostics.

Organize in Library

Pick up where you left off
Open Continue watching. Use favorites, bookmarks, or named collections to keep track of videos.
Find a saved file
Use Local files for media remembered through supported file handles. Your original file stays on your device.
Sync on your terms
Enable account sync in popup Settings to share eligible positions and bookmarks between your browsers. Stream URLs stay local.
